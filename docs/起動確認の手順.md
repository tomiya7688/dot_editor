# 起動確認の手順（Windows）

Dot Editorの窓が正しく開き、基本の操作ができるかを、**ダブルクリック1回**で確認する手順です。所要時間は5分ほどです。設計は[起動確認の設計書](design/startup-check.md)にあります。

## 準備

- Windowsのデスクトップにサインインしたパソコンで行ってください（リモート接続の画面や、画面のない環境では窓が開けません）。
- Python 3.10以上が入っていることが必要です。入っていなければ、画面に案内が出ます。

## 手順

1. このリポジトリのフォルダにある **`起動確認.bat`** をダブルクリックします。黒い画面が開きます。
2. 画面に「自動確認A」「自動確認B」の結果が出ます。数十秒かかります。何もしないで待ってください。
3. 実際のDot Editorの窓が開きます。**窓を操作しながら**、黒い画面に出る質問に答えます。答えは `y`（はい）、`n`（いいえ）、`s`（試せない）のどれかを入力して、Enterを押します。
4. 最後に「総合判定」が出て、`起動確認の結果.txt` が同じフォルダに保存されます。何かキーを押すと黒い画面が閉じます。

## 目で確認する項目

| 番号 | 確認すること | 見るところ |
| --- | --- | --- |
| 1 | 窓が開き、上のメニュー（ファイル・編集など）の文字が読める | 窓の上端。文字が欠けたり重なったりしていないか |
| 2 | キャンバスをクリックすると、その場所が塗られる | 窓の中央の白い升目。クリックした升目に色がつくか |
| 3 | ファイルメニューから保存し、もう一度開いても絵が残っている | 保存 → 新規作成 → 開く、の順に行い、絵が戻るか |
| 4 | Alt+H（またはヘルプメニュー）で、基本操作のヘルプが開く | ヘルプの窓が開き、文字が読めるか |

「試せない」ときは `s` を入力してください。成功とは数えず、結果に「試せなかった項目」として残ります。

## 結果の見方

| 総合判定 | 意味 | 次にすること |
| --- | --- | --- |
| 成功 | 自動確認がすべて成功し、目で見る項目に「いいえ」がなかった | 結果を貼って終わり |
| 失敗: 目視N | 目で見る項目Nが「いいえ」だった | 結果を貼り、何が起きたかを1行添える |
| 失敗: 自動確認A / B | 窓を作らない確認、または測定が失敗した | 結果を貼る（失敗の理由が入っています） |
| 未実行 | 窓を開けなかった | デスクトップに接続したWindowsで、もう一度実行する |

## 結果の貼り先

`起動確認の結果.txt` の中身を、そのまま次のIssueに貼ってください。作品の内容や個人の情報は入っていません。

- [Issue #67](https://github.com/tomiya7688/dot_editor/issues/67)（起動時間とメモリ、画面の見え方）
- [Issue #30](https://github.com/tomiya7688/dot_editor/issues/30)（キーボード操作の通し確認。項目が多いため、この手順とは別に行います）

## うまくいかないとき

| 症状 | 原因の例 | 対処 |
| --- | --- | --- |
| 「Pythonが見つかりません」 | Pythonが未インストール | Python 3.10以上を入れて、もう一度実行する |
| 「窓を開けませんでした」と未実行になる | リモート接続の画面、またはTkが動かない環境 | 手元のデスクトップで実行する。それでも出るときは、結果を貼って報告する |
| 黒い画面がすぐ閉じる | 起動に失敗した | コマンドプロンプトを開き、フォルダへ移動して `起動確認.bat` を実行すると、画面が残る |
