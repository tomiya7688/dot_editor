# この文書について

開発予定のものをまとめる 
AIは設計を軽く書いても良いが深い設計については各自機能説明書.mdを作成して記入すること
表はmdの表機能を利用し、図はmermaidを使用する
実装が完了したら項目を削除すること
優先度について 緊急性が高いものは優先度が高く書かれる、優先度を書いてないものは0である
優先度が低いものはマイナス
変更履歴:doc\ver.md
AI用メモ:doc\Agent.md
仕様書:doc\仕様書.md

共通コーディングルール
1クラスにつき1ファイル
1クラスは1つの責務を持つ
1関数につき1処理
なにかあたらしいものを追加したときには(機能単位)githubへアップロード、git管理する

# 実装の正本

- 製品バックエンドの正本は `rust/` のRust実装とする。
- Python版はGUI・参照実装として維持し、Rustとの互換性はproject JSON、描画結果、CLIの外部契約で確認する。
- 正しさの判断順は仕様・golden fixture、Rust Core、Rust CLI、Python参照実装、GUIとする。
- 移行順はRust Core、Rust CLI、Rust配布物。GUIのRust化は初期移行の必須条件にしない。

定期的なコミット、githubアップロード
ブランチは作業開始時に分けて終了してテストできたらそれをメインにする

# Rust Coreの移植（Issue #35）

RGBAラスタのpaint・erase・sample・4近傍fillを実装済み。
ResolutionFieldは任意解像度の画素中心で読み出し、表示解像度を変えても保持中の細部へ復帰できる。
局所パッチによるpaint・erase・discard_detailと細部判定を実装済み。preserveは未飽和の色差分を保持し、discardは対象セルだけを置換する。編集前のスナップショットは保持され、予算超過時は変更を適用しない。
次は論理解像度を持つCanvasとUndo/Redoを移植する。明示的なセル分割・折りたたみ、保持フィールド上のfill、保存形式は未移植。
