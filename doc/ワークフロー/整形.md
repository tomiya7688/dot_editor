# 変更対象を限定する整形手順

## 背景・目的・範囲

実装担当は、作業差分の整形漏れを防ぐため、実装後・テスト前に今回所有するファイルだけを整形してください。他者の未コミット変更、生成物、vendor、toolsのコピー、教材原文は整形しません。利用者の直接操作はありません。

Pythonは開発用依存のRuff **0.17.2**を使用します。pyproject.tomlでも同じ版を要求し、Python 3.10構文・100文字・LFを使用します。docstring内のコード例は書き換えません。Rustは既存のcargo fmtを維持します。今回の導入ではRustの設定・ソースを変更しません。

## 準備と作業後の実行

リポジトリルートで既存venvを使用してください。TLS検証を無効にせず、既存のPython trust確認後に開発依存を導入してください。

```powershell
.venv/Scripts/python.exe scripts/python_trust.py
.venv/Scripts/python.exe -m pip install -e '.[dev]'
.venv/Scripts/python.exe scripts/python_trust.py --check
```

次のパスを今回所有するPythonファイルへ置き換えてください。ディレクトリ指定・引数なしは拒否されます。

```powershell
.venv/Scripts/python.exe scripts/format_python.py scripts/format_python.py tests/test_python_format.py
.venv/Scripts/python.exe scripts/format_python.py --check scripts/format_python.py tests/test_python_format.py
```

その後、宣言コメント監査・関連テスト・自己レビュー・追加レビューを行ってください。指摘を修正した場合も再整形・再検証してください。整形は宣言コメントの意味や挙動の正しさを保証しません。

## CIと失敗時の確認

コミット後は次の1コマンドで、基準コミットからHEADまでに変更したsrc/scripts/testsのPythonだけを検査します。未コミット変更を比較対象へ追加せず、書換えも行いません。削除済みファイルと他言語は除外します。

```powershell
.venv/Scripts/python.exe scripts/format_python.py --check --base origin/main
```

CIの既存Declaration commentsジョブも同じ固定版・同じ入口で検査します。整形漏れは非0で失敗し、未知の基準・範囲外パスも失敗します。対象なしは明示して成功します。版不一致なら開発依存を再導入し、対象を確認して整形後に再検査してください。比較元とHEADが同じ場合は差分がないため、作業開始時の基準SHAを記録して使ってください。

既存の未変更Python全体は一括整形しません。Ruffの[公式formatter説明](https://docs.astral.sh/ruff/formatter/)と[固定版](https://pypi.org/project/ruff/0.17.2/)を参照できます。
